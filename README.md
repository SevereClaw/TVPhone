# TVPhone — телефон на ПК

Удобная оболочка для [scrcpy](https://github.com/Genymobile/scrcpy) под Windows: экран Android-телефона в окне на компьютере по Wi‑Fi, без проводов и командной строки.

## Скачать

Откройте [последний релиз](https://github.com/SevereClaw/TVPhone/releases/latest), скачайте `TVPhone-<версия>.zip`, распакуйте куда удобно и запустите **«Телефон на ПК.exe»**. scrcpy и adb уже лежат в архиве.

Дальше программа **обновляется сама**: при запуске и раз в 3 часа она проверяет релизы этого репозитория, скачивает новую версию и ставит её. Если в этот момент открыто окно телефона, она ждёт, пока вы его закроете. Автообновление можно выключить в разделе «Программа».

## Что умеет

- Подключение по QR-коду и автоподключение по Wi‑Fi, когда на телефоне включена «Отладка по Wi‑Fi»
- Панель у окна телефона: скриншот, запись, отправка файлов, камера, приложения, погасить экран, звук на ПК или на телефоне
- Пульт в одно нажатие: назад, домой, шторка, громкость, яркость, «Не беспокоить», фонарик, поворот, блокировка
- Приложения телефона в отдельных окнах
- Уведомления и входящие звонки на ПК
- Фото с телефона, галерея скриншотов и записей
- Профили качества, проверка связи, H.265, сглаживание для Wi‑Fi, счётчик кадров
- Трей, автозапуск, горячие клавиши, оформление в стиле Persona 4 Golden со звуками

Подробная инструкция: [docs/Как пользоваться.txt](docs/Как%20пользоваться.txt).

## Сборка

Нужен Go 1.24, сторонних зависимостей нет.

```sh
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H windowsgui -s -w -X main.appVersion=3.0" -o "Телефон на ПК.exe" .
```

Положите exe в папку с `scrcpy.exe` и `adb.exe`. Значок программы лежит в `rsrc_windows_amd64.syso`; его генератор находится в `tools/mksyso`.

Тесты: `go test ./...`

## Выпуск новой версии

```sh
git tag -a v3.1 -m "Что изменилось"
git push origin v3.1
```

GitHub Actions ([release.yml](.github/workflows/release.yml)) проверяет код, собирает exe с номером версии из метки, добавляет последний scrcpy и публикует релиз с архивом `TVPhone-3.1.zip`. Установленные копии программы подхватят его автоматически. Описание релиза берётся из сообщения метки.
