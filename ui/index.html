Подключить телефон

    
  

  

    
    
    
    
  


  

    

      

      

        
    
          
  1. Телефон и компьютер должны быть в одной Wi-Fi сети.
    2. 
          
  2. На телефоне откройте Настройки → Для разработчиков → Отладка по Wi-Fi и включите её.
    3. 
          
  3. Нажмите «Подключить устройство с помощью QR-кода» и наведите камеру на код слева.
    4. 
        

        
Сопряжение нужно один раз. Потом телефон будет подключаться сам — даже когда меняется порт.

        
Жду телефон…

        

      

    

  


  

    

      
На телефоне: Отладка по Wi-Fi → Подключить устройство с помощью кода. Перепишите адрес и код из окна на телефоне.

      
      
      
      

    

  


  

    

      
Если телефон уже сопряжён с этим ПК, хватит адреса. Он показан вверху экрана «Отладка по Wi-Fi».

      
      
      

    

  


  

    
    
      
  1. Включите на телефоне Для разработчиков → Отладка по USB.
    2. 
      
  2. Подключите кабель и разрешите отладку в окне на телефоне.
    3. 
      
  3. Телефон появится в списке. Кнопка «Перейти на Wi-Fi» на его карточке отвяжет его от кабеля.
    4. 
    

    
Так можно подключить и старые телефоны на Android 10 и ниже, где нет «Отладки по Wi-Fi».

  




  

    
Открыть приложение

    
  

  

    
Приложение откроется в отдельном окне на ПК, а телефон в руке останется свободным. Окно можно растягивать — приложение подстроится.
